# Open-source Maintenance Workbench

项目简称：`osmw`

Open-source Maintenance Workbench 是面向开源维护者的 Issue、Pull Request、Agent 和项目文档协同工作台。

## 项目目录

- `产品文档/主要管理文档`：PRD、架构和开发规范等主要项目文档
- `ui设计`：界面流程、线框图和视觉设计
- `前端`：前端应用代码
- `后端`：后端服务、任务队列和 GitHub 集成
- `测试`：测试用例、测试数据和质量验证记录
- `部署`：本地、测试和生产环境部署配置
- `脚本`：开发、检查和数据处理脚本
- `.github`：Issue/PR 模板、工作流和仓库协作配置
